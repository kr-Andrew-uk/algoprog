## Виконав: Крук Андрій Ігорович (ІР - 11)

## Лабораторна робота №5 (Варіант 2 Рівень 3)


Дано шахівницю, знайдіть найкоротшу відстань (мінімальна кількість ходів),
яку пройшов кінь, щоб досягти заданого пункту призначення з заданого
джерела.
Кінь може ходити у восьми можливих напрямках від даної клітини
Наприклад,
Вхідні дані:
N = 8 (дошка 8 × 8)
Джерело = (7, 0)
Пункт призначення = (0, 7)

Результат: мінімальна необхідна кількість кроків

Вхідні дані містяться у файлі input.txt
Результуючий файл має містити кількість ходів
Результуючий файл output.txt має містити значення найкоротшого шляху від
початкової точки до точки призначення
